Hallazgos por Prioridad

{{-- Prioridad 1: N+1 Crítico --}}

1. Cuello de botella Crítico: N+1 en Tasa del Dólar (CRÍTICO)

Problema: El modelo Product ejecuta una consulta a la base de datos para obtener el valor del dólar cada vez que se calcula el precio en bolívares (getPriceBsAttribute). En un listado de 12 productos, esto genera 24 consultas adicionales innecesarias.

Ubicación: app/Models/Product.php - método getDollarRate().

Solución: Implementar un Singleton o Cache de sesión para el valor del dólar durante el ciclo de vida de la petición.

// Ejemplo de mejora en Product.php
public static function getDollarRate()
{
    return once(fn() => \App\Models\DollarValue::latest('date')->first()?->value ?? 0);
}
{{-- Prioridad 2: Eager Loading --}}

2. Carga Perezosa (N+1) en Listados (MEDIO)

Problema: Los controladores de la tienda no están cargando las relaciones necesarias (category, brand) de forma anticipada. Si el componente product-card o el listado accede a estas relaciones, se genera una consulta por cada producto.

Ubicación: ProductController.php - métodos shop, byBrand, byCategory.

Solución: Usar with(['category', 'brand']) en las consultas de Eloquent.

// En ProductController.php
$products = $query->with(['category', 'brand'])->paginate(12);
{{-- Prioridad 3: View Composer --}}

3. Optimización de Consultas Globales (MEDIO)

Problema: El ViewServiceProvider inyecta los items del carrito en TODAS las vistas (incluyendo parciales). La consulta al carrito se ejecuta en cada petición aunque la página no lo necesite explícitamente.

Ubicación: app/Providers/ViewServiceProvider.php.

Solución: Cachear el carrito en un servicio Singleton o limitar el composer solo a las vistas que realmente lo utilizan (ej. el layout principal).

{{-- Prioridad 4: Infraestructura --}}

4. Configuración de Cache y Sesión (BAJO)

Problema: Actualmente se utiliza database o file como driver de cache y sesión. Para una tienda con tráfico concurrente, esto genera latencia de E/S en disco o base de datos.

Solución: Cambiar a redis en el entorno de producción (.env).

CACHE_STORE=redis
SESSION_DRIVER=redis
QUEUE_CONNECTION=redis
{{-- Prioridad 5: Indexación de DB --}}

5. Índices en Base de Datos (BAJO)

Problema: Columnas frecuentemente filtradas como is_active o is_featured en la tabla products no tienen índices.

Solución: Crear una migración para añadir índices a estas columnas para acelerar las consultas de filtrado en la tienda.

Recomendaciones Adicionales

  • Optimización de Imágenes: Implementar redimensionamiento automático al subir imágenes (usando Intervention Image) y servir formatos WebP.
  • Laravel Optimize: Asegurarse de ejecutar php artisan optimize en el proceso de despliegue para cachear rutas y configuración.
  • Compresión Assets: Verificar que Vite esté generando archivos minificados (npm run build) y usar Gzip o Brotli en el servidor (Nginx/Apache).
